# 3D models

The `.glb` models and thumbnails are not included in this repository while their licences are being confirmed.

The backend serves this folder at `/models_3d` and needs it to exist in order to start. Without the model files, the app runs but 3D furniture and thumbnails will not load.

To use your own models, put a `.glb` and a `.png` thumbnail here with the same base filename, for example `modern_sofa.glb` and `modern_sofa.png`.
